# Haskell SDK Guide

You are helping a user work with panproto's Haskell bindings. The bindings provide two backends behind a shared typeclass interface.

## Installation

```cabal
build-depends: panproto >= 0.41
```

The cabal package is not yet published to a registry. Install from source via the `bindings/haskell/` directory in the panproto repository.

## Architecture

Two backends meet at the same capability typeclasses:

### Native backend

Pure-Haskell implementation of the panproto subset that does not need the Rust core. Useful when:
- You want a Rust-runtime-free dependency
- You need to embed panproto in an existing Haskell pipeline
- You are property-testing the canonical exchange format

### Rust backend

FFI-backed implementation linking against `libpanproto_c` (the C ABI generated by `safer-ffi`):
- **Hot path**: opaque `u32` handles into a thread-local slab with no serialization per call
- **Cold path**: CBOR via `ciborium` (Rust) / `cborg` (Haskell) for Protocol ingest, schema introspection, and structured errors

## Capability typeclasses

Both backends implement the same typeclasses returning plain `IO`:

```haskell
class ProtocolBackend m where
  fromCanonical :: CanonicalProtocol -> m Protocol
  toCanonical :: Protocol -> m CanonicalProtocol
  releaseProtocol :: Protocol -> m ()

class SchemaBackend m where
  fromCanonicalSchema :: CanonicalSchema -> m Schema
  toCanonicalSchema :: Schema -> m CanonicalSchema

class SchemaValidate m where
  validateSchema :: Protocol -> Schema -> m ValidationResult
```

`mtl` users lift via `liftIO`; `effectful` users go through a separate `panproto-effectful` adapter.

## Panic safety

Every `#[ffi_export]` entry point is wrapped in `std::panic::catch_unwind`. Panics are converted to a CBOR-encoded error envelope retrievable via `pp_last_error_take()`. The release profile uses `panic = "unwind"` (not abort), so panics never tear down the GHC runtime.

## Wire protocol

| Path | Encoding | When |
|------|----------|------|
| Hot | `u32` handle + `#[repr(C)]` structs | Every schema/migration/lens call |
| Cold | CBOR via `ciborium`/`cborg` | Protocol ingest, introspection, errors |

## Status

The Haskell binding ships as of panproto v0.41.0. The capability surface grows release by release alongside `panproto-c`.
